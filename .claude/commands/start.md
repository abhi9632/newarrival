# /start -- Begin a session

1. Read the HANDOFF summary the SessionStart hook printed. That is the state.
   Do not read all of HANDOFF.md unless the summary is missing something you need.
2. Read `CLAUDE.md` if it is not already loaded.
3. Name the effort tier for the work you have been given: Quick, Feature or Foundation.
4. Confirm orientation in one short paragraph: last completed work, what is next,
   and anything you need from the human.

Do not load any `rules/` file until the task calls for it, and do not start building
until the human confirms.
