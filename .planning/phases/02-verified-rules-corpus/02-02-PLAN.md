<verification_method>
Binding for every figure in this plan. Restated from 02-01 because this is the task that writes the figures.

1. Fetch the page with WebSearch or WebFetch before writing the record. The model's training data is NOT an acceptable source for any figure here. Several of these numbers changed in recent years, which is exactly the trap this phase exists to avoid.
2. `sourceUrl` is the URL actually fetched. The URLs named below are starting points, not facts. If one redirects or 404s, find the current page with WebSearch and record where you landed.
3. `verifiedOn` is today's date on every record.
4. Three figures are flagged by `docs/CONCEPT.md` line 73 as must verify rather than must remember, and are the three most likely to be wrong from memory: the subclass 500 work limit per fortnight, the superannuation guarantee rate, and whether Italy is currently on the Reciprocal Health Care Agreement country list. If any of the three cannot be confirmed on a live page, cut the record that carries it.
5. Prefer the page that states the figure over a page that mentions it. Where Home Affairs and the legislation both state a condition, cite the page whose wording you actually transcribed.
</verification_method>

Write `title` and `detail` as visitor facing copy that renders directly on the timeline. `detail` states what the rule requires and what happens if it is missed. It never states what the reader ought to do: no second person recommendation, no eligibility assertion, no first person plural recommendation. The eleven gates will reject those phrasings, and the reason is legal rather than stylistic, unregistered paid immigration assistance is an offence in Australia. No em dash, no en dash used as a pause, no angle brackets.

Set `instrument` to the named thing, not a vague one. For a visa condition that is the Migration Regulations 1994 Schedule 8 condition number. For an agency rule it is the agency page title. `agency` is the display name that appears on the card, for example Department of Home Affairs or Services Australia.

If a page states a figure you did not expect, the page wins. Write what the page says and note the surprise in the summary, that is the finding this phase exists to produce.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| live .gov.au page to corpus | A human readable legal page is transcribed into machine readable JSON by an agent. Transcription error is the primary risk in this plan. |
| model memory to corpus | The lowest trust input in the project. A figure that arrives from training data rather than from a fetched page is unverified by construction, and three specific figures here are known to have changed recently. |
| corpus to rendered UI | Corpus strings cross into React components in Phase 3, including one string that becomes an anchor href. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Tampering | the three flagged figures: 500 work limit, super guarantee rate, RHCA country list | critical | mitigate | Each is named explicitly in `<verification_method>` as must verify, each must be read off a live page, and the record is cut rather than guessed if the page cannot be reached |
| T-02-07 | Spoofing | `sourceUrl` on a newly added record | high | mitigate | `source-host` gate from 02-01 rejects any non https or non .gov.au host, so a private aggregator cannot be cited as the source |
| T-02-08 | Repudiation | the audit trail behind an on screen figure | high | mitigate | `required-field` and `verified-date` gates make instrument and a fresh verified date mandatory; the summary additionally lists the URL fetched per record |
| T-02-09 | Elevation of Privilege | corpus copy rendered by React | medium | mitigate | `markup-copy` gate rejects angle brackets in title and detail, closing the injection path at the data layer |
| T-02-10 | Information disclosure | user profile data | low | accept | No personal identifier is collected or persisted anywhere in the product and this plan adds no storage |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs nothing and touches one JSON data file. No package legitimacy audit is required and none is claimed |
</threat_model>
