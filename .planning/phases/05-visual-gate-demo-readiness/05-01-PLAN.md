<objective>
Close the visual gate on every demo screen at 375 and 1280 with committed evidence, make the demo
path repeatable on the public Vercel URL rather than only on localhost, and sweep the visitor facing
surface for what would embarrass the project on stage.

This phase adds no features. It is the last phase that may touch feature code, and everything it
touches is verification of work Phases 1 through 4 already shipped.

Purpose: SHIP-02 is the one requirement here. The rest is the difference between a build that works
on the machine it was built on and a demo that survives a cold start at 23:30 in front of judges,
four hours after freeze, run by someone nervous and short on time.

Output: eleven screenshots under `docs/visual-gate/`, five judged gate rows with written answers in
`design-system/README.md`, one runnable gate at `scripts/check-demo.sh`, a cold start walk log in
`docs/demo-prep.md`, and the `Live URL` field in `AGENTS.md` filled so the freeze gate can pass.

Time budget: 30 minutes, ending before the 19:30 feature freeze.
</objective>
